# 個人開発技術スタック

## 技術選定で重視すること

- 運用コストの低さ
  - 初期費用が最小限であること
  - ユーザーが増えたときだけスケールしやすいこと
  - 保守の手間が少ないこと
- 開発体験の良さ
  - 環境構築がしやすいこと
  - 開発がしやすいこと
- 情報の豊富さ
  - 公式ドキュメントが充実していること
  - 技術記事が多いこと

## 推奨構成

### 基本

- 言語
  - TypeScript (以降のライブラリ等の構成は TypeScript 前提とする)
- フレームワーク・UIライブラリ
  - React + Next.js
  - Tailwind CSS
  - shadcn/ui
- 認証
  - NextAuth.js
- テスト
  - Vitest
  - Playwright
  - Testing Library
- ホスティング
  - Cloudflare Workers
- DB
  - Cloudflare D1 (SQLite)
- ドメイン取得
  - Cloudflare

### 必要に応じて追加するライブラリ・サービス

- オブジェクトストレージ
  - Cloudflare R2
  - Cloudflare Images
- 課金・決済
  - Stripe
- メール
  - Resend
- CDN
  - Cloudflare

## 初期セットアップ方法

- `pnpm create cloudflare@latest my-next-app --framework=next`
  - https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/
  - Next.js on cloudflare テンプレートから始める場合
- [Vercel v0](https://v0.dev/)
  - AI により初期デザインを作る場合(Cloudflare用設定は自動生成されないため注意)

## 選定候補比較

### 言語・フレームワーク選定

- 推奨
  - [TypeScript](https://www.typescriptlang.org/)
    - フロントエンドとバックエンドを同じ言語で書けるため学習コストが低い, 型安全
  - [Next.js](https://nextjs.org/)
    - フルスタックで書ける, 技術記事が豊富, エコシステムが豊富
- その他
  - [Nuxt.js](https://nuxt.com/)
    - Vue.js のフルスタックフレームワーク, Next.jsに比べると勢いが落ち目
  - [Remix](https://remix.run/)
    - まだ知名度が低い

### UIライブラリ

- 推奨
  - [Tailwind CSS](https://tailwindcss.com/)
    - CSSライブラリ, 高度にカスタマイズ可, CSS クラス名を考えなくてよい
  - [shadcn/ui](https://ui.shadcn.com/)
    - UI コンポーネント, 高度にカスタマイズ可, デフォルトスタイルが充実
- その他
  - [Radix UI](https://www.radix-ui.com/)
  - [Headless UI](https://headlessui.com/)
  - [CSS Modules](https://github.com/css-modules/css-modules)
  - [styled-components](https://styled-components.com/)
  - [Emotion](https://emotion.sh/docs/introduction)
  - [Chakra UI](https://www.chakra-ui.com/)
  - [Material UI(MUI)](https://mui.com/material-ui/)

### 認証

- 推奨
  - [NextAuth.js](https://next-auth.js.org/)
    - 機能豊富, サードパーティ連携容易, 複雑な機能は苦手, Auth.jsに改名
  - [Better Auth](https://better-auth.com/)
    - NextAuth.js を統合したライブラリ, 今後はこちらがメンテナンスされる
- その他
  - [Supabase Auth](https://supabase.com/docs/guides/auth)
    - 複雑な機能可, 無料枠多い
  - [Firebase Authentication](https://firebase.google.com/docs/auth)
    - 複雑な機能可, 無料枠多い
  - [Auth0](https://auth0.com/)
    - 無料枠少ない
  - [Clerk](https://clerk.com/)
    - 無料枠少ない
  - [Amazon Cognito](https://aws.amazon.com/jp/cognito/)
    - 無料枠少ない

### テスト

- 推奨
  - 単体テスト
    - [Vitest](https://vitest.dev/)
      - OSS, Vite 製, React/Next.js に最適化
  - E2Eテスト
    - [Playwright](https://playwright.dev/)
      - OSS, Microsoft 製
  - 補助
    - [Testing Library](https://testing-library.com/)
      - UIテスト補助ライブラリ
- その他
  - 単体テスト
    - [Jest](https://jestjs.io/ja/)
      - OSS, Facebook 製, React/Next.js に最適化
  - E2Eテスト
    - [Cypress](https://www.cypress.io/)
    - [Puppeteer](https://pptr.dev/)
    - [Selenium](https://www.selenium.dev/ja/documentation/)
  - Component
    - [Storybook](https://storybook.js.org/)

### ホスティング

- 推奨
  - [Cloudflare Workers](https://www.cloudflare.com/ja-jp/developer-platform/products/workers/)
    - サーバレス, 無料枠が多い, JS/TS/Python/Rust 対応
- その他
  - [Vercel](https://vercel.com)
    - 無料枠で商用利用不可
  - [Cloudflare Pages](https://www.cloudflare.com/ja-jp/developer-platform/products/pages/)
    - 主に静的配信用
  - [AWS Lambda](https://aws.amazon.com/jp/lambda/)
    - サーバレス, 無料枠が多い, 多言語, Docker 可, 実行時間長いのも可
  - [Cloud Run](https://cloud.google.com/run?hl=ja)
  - [Supabase](https://supabase.com/)
    - 認証, Postgres, ストレージ, サーバレス関数
  - [Firebase](https://firebase.google.com/?hl=ja)
    - 認証, NoSQL, ストレージ, サーバレス関数
  - [Netlify](https://www.netlify.com/)

### DB

- 推奨
  - [Cloudflare D1](https://www.cloudflare.com/ja-jp/developer-platform/products/d1/)
    - SQLite, 5GB無料, コストが最も安い, Prisma 対応
- その他
  - [Supabase database](https://supabase.com/docs/guides/database/overview)
    - Postgres, 512MB無料, 認証, ストレージ(S3), GraphQL
  - [Vercel Storage](https://vercel.com/docs/storage)
    - Postgres, 512 MB無料
  - [Firestore](https://firebase.google.com/docs/firestore?hl=ja)
    - NoSQL, 無料枠大きい
  - [Neon](https://neon.tech/)
    - 有料プランが安い, 旧Vercel Postgres
  - [Upstash](https://upstash.com/)
    - Redis, キャッシュで使える
  - [PlanetScale](https://planetscale.com/)
    - 無料枠なし

### オブジェクトストレージ

- 推奨
  - [Cloudflare R2](https://www.cloudflare.com/ja-jp/developer-platform/products/r2/)
    - 10GB 無料
