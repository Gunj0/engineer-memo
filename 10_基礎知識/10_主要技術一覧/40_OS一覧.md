# OS一覧

- 代表的な OS を系譜ごとに整理
- Linux は厳密にはカーネルだが、このページでは関連する主要ディストリビューションや派生 OS もあわせて扱う

## UNIX系のOS

### UNIX

- UNIX: 1969 年に AT&T ベル研究所で開発された OS

### BSD系

- macOS: Apple のデスクトップ・ノート PC 向け OS。Darwin をベースにした BSD 系 UNIX
- iOS: Apple のモバイル製品向け OS。macOS と同系統の基盤を持つ
- FreeBSD: 安定性重視の BSD 系 OS
- OpenBSD: セキュリティ重視の BSD 系 OS
- NetBSD: 移植性重視の BSD 系 OS

### Linux系

- Linux: Linus Torvalds が開発した UNIX ライクな OSS カーネル
- Ubuntu: Debian 系の主要ディストリビューション。初心者にも扱いやすい
- Linux Mint: Ubuntu ベースのデスクトップ向けディストリビューション
- Debian: 安定性重視の Linux ディストリビューション
- Fedora: Red Hat 系のコミュニティディストリビューション
- Red Hat Enterprise Linux: 企業利用の多い商用 Linux ディストリビューション
- CentOS Stream: Red Hat Enterprise Linux 関連の継続開発系ディストリビューション
- Rocky Linux: CentOS Linux の後継候補として普及した RHEL 互換ディストリビューション
- AlmaLinux: RHEL 互換のコミュニティディストリビューション
- openSUSE: SUSE 系の OSS ディストリビューション
- Android: Linux カーネルを採用するモバイル向け OS

### System V系・商用UNIX

- Solaris: Sun Microsystems が開発した商用 UNIX 系 OS。SVR4 をベースに BSD の要素も取り込んでいる
- OpenSolaris: Solaris のオープンソース版として公開されていたが終了済み
- illumos: OpenSolaris 系の主要なオープンソース後継プロジェクト
- AIX: IBM が提供する商用 UNIX 系 OS
- HP-UX: Hewlett Packard Enterprise が提供する商用 UNIX 系 OS

## Windows系のOS

### クライアント向け

- Windows 11: Microsoft の現行主要デスクトップ向け OS

### サーバ向け

- Windows Server: Microsoft のサーバ向け OS
