# Route53

- マネージドDNS (Domain Name System)サービス
  - レジストラサービスであり、ネームサーバーサービスでもある
  - AWSのリソースにドメイン名を紐づけることができる
  - ドメイン登録、DNSルーティング、ヘルスチェックなどの機能を提供する
  - 料金はホストゾーンの数、DNSクエリの数、ヘルスチェックの数に基づいて課金される
  - (+)
    - 高い可用性とスケーラビリティを提供する
    - AWSの他のサービスとシームレスに統合できる
    - グローバルなDNSネットワークを利用して、低レイテンシーで信頼性の高いDNSサービスを提供する
    - ドメイン登録サービスも提供している
  - 制約
    - ドメイン登録は一部のトップレベルドメイン(TLD)に限定されている
    - DNSクエリの数が多い場合、料金が高くなる可能性がある
    - 一部のDNS機能(例: DNSSEC)はサポートされていない

## DNSについて

- Aレコード: ドメイン名をIPv4アドレスに紐づける
  - AWSではALIASレコードでALBやCloudFrontなどのAWSリソースにドメイン名を紐づけることもできる
- AAAAレコード: ドメイン名をIPv6アドレスに紐づける
- NSレコード: ドメイン名を管理するDNSサーバーを指定する
- SOAレコード: ドメイン名の管理情報を指定する
- CNAMEレコード: ドメイン名を別のドメイン名に紐づける
  - AWS Certificate Managerで証明書を取得するときに作る
- MXレコード: メールサーバーのドメイン名を指定する
- TXTレコード: ドメイン名にテキスト情報を紐づける

## 機能

- フェイルオーバー: ヘルスチェックを利用して、障害が発生した場合にトラフィックを別のリソースに切り替えることができる
