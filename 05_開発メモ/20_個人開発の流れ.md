# 個人開発の流れ

- ゴール設定
  - 解決したい課題は？
  - どんな人に使ってほしい？
- 機能の洗い出し
  - 必須機能
    - CRUD
    - ログイン・認証・ログアウト
  - 非必須機能
- 技術選定
  - フロントエンド
  - バックエンド
  - DB
  - インフラ
- 画面設計
  - 必要な画面洗い出し
  - ワイヤーフレーム
    - 分かりやすいデザイン
    - 説明が少なく、直感的に使える
  - デザインコンセプト
    - 例: シンプル, ミニマル, かわいい, クール, 高級感
- 開発
  - フロントエンド
  - バックエンド
  - DB
  - インフラ
- その他
  - ドメイン取得
  - デプロイ環境構築
