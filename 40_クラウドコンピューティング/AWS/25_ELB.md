# ELB

- Elastic Load Balancing
  - 複数のEC2インスタンスにトラフィックを分散するサービス
  - 可用性とスケーラビリティを向上させるために使用される
  - ヘルスチェック機能があり、正常なインスタンスにのみトラフィックを送ることができる
  - ターゲットグループを使用して、EC2インスタンスやIPアドレスなどのターゲットを管理する
  - Auto Scalingと組み合わせることで、トラフィックの増減に応じてEC2インスタンスの数を自動的に調整することができる
  - タイプ:
    - Application Load Balancer (ALB): HTTP/HTTPSトラフィックに最適化されている
    - Network Load Balancer (NLB): TCP/UDPトラフィックに最適化されている
    - GWLB(Gateway Load Balancer): 仮想アプライアンスのためのロードバランサー
    - Classic Load Balancer (CLB): レガシーアプリケーション向け, 現在は非推奨

## 作成手順

- ターゲットグループを作成
  - ターゲットタイプ: インスタンス、IPアドレス、Lambda関数などから選択
  - ヘルスチェックの設定
- ロードバランサーを作成
  - タイプを選択
  - VPCとサブネットを選択
  - セキュリティグループを設定
    - HTTPトラフィックを許可し、EC2インスタンスではこのSGからのトラフィックを許可する
