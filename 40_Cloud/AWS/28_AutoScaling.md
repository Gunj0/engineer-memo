# Auto Scaling

- トラフィックの増減に応じて EC2 インスタンスの数を自動的に調整するサービス
  - 起動テンプレートとスケーリングポリシーを設定して、負荷に応じたスケーリングが可能
  - コスト効率と可用性を向上させる
  - CloudWatch アラームと連携して、CPU使用率などのメトリクスに基づいてスケーリングをトリガーすることができる

## 作成手順

- 起動テンプレートを作成
  - インスタンスタイプ、AMI、キーペア、セキュリティグループなどの設定を定義
- Auto Scaling グループを作成
  - 起動テンプレートを指定
  - 最小/最大/希望するインスタンス数を設定
  - スケーリングポリシーを設定
  - CloudWatch アラームを設定して、スケーリングをトリガーする条件を定義
- ELB と組み合わせる場合は、ターゲットグループを指定して、スケーリングされたインスタンスを自動的にロードバランサーに登録することができる
