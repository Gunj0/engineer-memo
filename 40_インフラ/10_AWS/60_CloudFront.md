# CloudFront

- フルマネージドのCDNサービス
  - エッジロケーション: 世界中のデータセンターで、ユーザーに近い場所からコンテンツを配信する
  - キャッシュの有効期限を設定できる
  - AWS Certificate Manager(ACM)と統合して、SSL/TLS証明書を簡単に管理できる
  - WAFと統合して、Webアプリケーションファイアウォールを利用して、悪意のあるトラフィックからコンテンツを保護することができる

## 用語

- ディストリビューション: コンテンツ配信の設定を定義する単位
- オリジングループ: 複数のオリジンサーバをグループ化して、フェイルオーバーや負荷分散を行うことができる
  - S3, EC2, ELBなどをオリジンサーバとして指定できる
- ビヘイビア: リクエストのパスパターンに基づいて、異なるオリジングループやキャッシュ設定を適用することができる
- Lambda@Edge: CloudFrontのエッジロケーションでLambda関数を実行して、リクエストやレスポンスをカスタマイズすることができる
- セキュリティ: AWS WAFと統合して、Webアプリケーションファイアウォールを利用して、悪意のあるトラフィックからコンテンツを保護することができる
- ロギング: CloudFrontアクセスログをS3バケットに保存して、アクセスパターンやトラフィックの分析に利用することができる
- 料金は、データ転送量、リクエスト数、Lambda@Edgeの実行時間などに基づいて課金される
  - (+)
    - 高速なコンテンツ配信を提供する
    - グローバルなエッジロケーションを利用して、ユーザーに近い場所からコンテンツを配信する
    - AWSの他のサービスとシームレスに統合できる
    - セキュリティ機能を提供している
    - 人気オブジェクトから、キャッシュのヒット率が確認できる

## 使い方

- キャッシュポリシーの作成
  - キャッシュの有効期限や、クエリ文字列、ヘッダー、クッキーなどのキャッシュキーの設定を行う
- ディストリビューションの作成
  - オリジンサーバの指定: S3バケット、EC2インスタンス、ELBなどを指定する
  - ビヘイビアの設定
  - キャッシュポリシーの適用
  - SSL/TLS証明書の設定
  - AWS WAFの設定
- デプロイ
