# SNS, SQS

## SNS (Simple Notification Service)

- Pub/Subのメッセージングサービス
  - トピックを作成し、サブスクライバーがそのトピックに対して購読する
  - 配信側はトピックにメッセージ送信するだけで、複数のサブスクライバーに同時に配信可能なため、疎結合で拡張性が高い
  - メッセージは複数のプロトコル（HTTP/HTTPS、Email、SMS、SQSなど）で配信可能

## SQS (Simple Queue Service)

- メッセージキューサービス
  - 基本は順序を保証しないが、順序を保証するためのFIFOキューも提供
  - 可視性タイムアウト: メッセージが消費されるまでの時間を設定できる
  - 遅延キュー: メッセージの配信を遅らせることができる
  - デッドレターキュー: 処理に失敗したメッセージを保存するためのキュー
