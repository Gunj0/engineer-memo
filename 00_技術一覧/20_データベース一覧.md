# データベース一覧

- 主要なデータベース一覧

## データベース比較

| 項目     | RDB                                                  | NoSQL                                                          | NewSQL                                                       |
| -------- | ---------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| 主な特徴 | 表形式で関係を扱い、SQL で操作する                   | 用途に応じて柔軟なデータモデルを採る                           | RDB の整合性と分散性能の両立を目指す                         |
| 主な用途 | 業務システム, 台帳, 複雑な集計                       | 高トラフィック, 大規模データ, 柔軟なスキーマ                   | 大規模トランザクション, グローバル分散                       |
| 強み     | ACID 特性, 複雑なクエリ, 関係データの整合性          | 水平分散しやすい, スキーマ変更に強い, 高可用構成を取りやすい   | SQL を維持しつつ高可用・高スケーラビリティを狙える           |
| 注意点   | 水平分散が難しいことがある, スキーマ変更コストが高め | 製品ごとの差が大きい, 複雑な結合や厳密な整合性設計に工夫が要る | 構成や運用が複雑になりやすく、採用事例や選択肢が比較的少ない |
